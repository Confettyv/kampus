# Кампус

Веб-сервис для первокурсника: сколько можно потратить сегодня, кто кому должен в комнате,
предупреждение о мошеннической схеме перед переводом и каталог студенческих скидок у корпуса.

Командный проект ЭФБО-13-25, 28.09–22.11.2026. Релиз v1.0 на своём домене по HTTPS.

## Модули

| Модуль | Что делает |
|---|---|
| Аккаунт | Регистрация, вход, профиль, удаление аккаунта вместе с данными |
| Бюджет | Стипендия и дата следующей, операции, лимит «сегодня можно потратить» |
| Сплит | Группа комнаты, приглашение по ссылке, общие расходы поровну до копейки, балансы |
| Защита | Проверка перевода по признакам схемы и предупреждение до перевода |
| Скидки | Каталог студенческих предложений с фильтром по категориям |

Реальных платежей и банковских API нет: переводы моделируются, реквизиты карт не собираются.
